# Proposal: Enforce Atomic Commit-Push-Publish Deployment Triad, 5-Phase Pipeline & Canonical Brand Logo Registry

> **Architect:** antigravity
> **Architect Role:** assigned

## Why

As part of the Parallel Triad Value-Absorption mandate (`theme.tools` + `install.doctor` + `agent-skills`), workstation agent harnesses and managed fleet nodes must enforce a deterministic 5-Phase Prompt Pipeline and an Atomic Commit-Push-Publish Deployment Triad on every web or Cloudflare Worker project turn. Without an explicit workstation harness contract, agent turns can stop after local code edits or commits without pushing to `origin/main`, deploying live via `wrangler deploy`, purging the Cloudflare CDN cache, or verifying production edge routes (`https://<domain>/`, `/api/health`, `/og.png`, `/favicon.svg`, `/apple-touch-icon.png`). Additionally, the Canonical Brand Logo Registry must be synchronized across `install.doctor` with `questionl.ink` (`/logos/10-sovereign-questionlink-crown-ideogram.png` and `1200x630` `/og.png`).

## What Changes

1. **5-Phase Workstation Agent Harness Pipeline**:
   - Every prompt execution follows the 5-Phase pipeline:
     1. **MECH Prompt Hydration**: 3-Tier MECH context (`12/12` zero-miss dimensions, `3600s` KV-cache prefix pinning) + SHA-256-pinned primary vendor documentation research.
     2. **OpenSpec Architecture**: Frontier Architect group conference (`claude` + `codex` + `gemini`/`antigravity`, never `opencode`) using Blind Generation -> Cross-Critique -> Weighted Consensus to author and lock `openspec/changes/<change-id>/{proposal.md,design.md,tasks.md,specs/}`.
     3. **Golden Path TDD**: Homepage-first deep UI Golden Path Nx TDD (`100%` unit coverage, `90%+` E2E across 16 visual states, `0.333s` OKLCH transitions, and 6 Playwright breakpoints `320/375/768/1024/1440/1920`).
     4. **Recursive Scope Expansion**: Self-expanding 2nd- and 3rd-order recommendation loop implementing 100% of recommendable ideas in the same turn until `0` remain.
     5. **Parallel Triad Value Absorption**: Concurrent extraction of reusable UI/library code into `theme.tools`, workstation/provisioning scripts and harness policies into `install.doctor`, and skills/rules into `agent-skills`.
2. **Atomic Commit-Push-Publish Deployment Triad**:
   - Every web/worker project turn must execute the atomic deployment triad before completion:
     - `git commit` -> `git push origin main`
     - `wrangler deploy` / live publish + Cloudflare CDN cache purge
     - Live edge HTTP verification of `https://<domain>/`, `/api/health`, `/og.png`, `/favicon.svg`, and `/apple-touch-icon.png`.
