# Spec: Cross-Platform Site Build (`cross-platform-site-build`)

## ADDED Requirements

### Requirement: Standalone Stencil Build Without Prebuilt Docusaurus Output
The `site/` workspace MUST complete `npm run build` and `npm start` without error when `site/docs/build` is absent, and MUST copy `site/docs/build` into `site/www/docs` when `site/docs/build` exists.

#### Scenario: Fresh clone standalone build without docs/build
- **WHEN** a contributor runs `npm run build` in `site/` and `site/docs/build` does not exist
- **THEN** Stencil completes prerendering without `ENOENT` copy errors and writes a non-empty `site/www/index.html`

#### Scenario: Combined build with prebuilt docs/build
- **WHEN** `site/docs/build` exists prior to Stencil compilation
- **THEN** Stencil copies `site/docs/build/**` into `site/www/docs/**`

### Requirement: Symlink-Free Stylesheet Selection on Windows
The `site/` build and `npm run build:noscript` script MUST compile default and offline stylesheets without reading or mutating `site/src/global/style.scss` or invoking POSIX `rm`, `ln`, or `cp` utilities.

#### Scenario: Windows checkout with core.symlinks=false
- **WHEN** Git checks out `site/src/global/style.scss` as a plain-text file rather than a symlink and `npm run build` or `npm run build:noscript` runs
- **THEN** Sass compilation succeeds using `style-default.scss` or `style-offline.scss` directly and `site/src/site-noscript.css` is written without modifying tracked files

### Requirement: Cross-Platform Documentation Prebuild Fallback
`site/docs` `prebuild` and `generate-plugin-docs` scripts MUST run via Node.js across Windows, macOS, and Linux, delegating to `site/docs/scripts/markdown.sh` on POSIX hosts when `bash`, `rsync`, `shdoc`, and `task` are installed and falling back to a pure Node.js mirror and reference generator otherwise.

#### Scenario: Windows or minimal workstation without shdoc/rsync/task
- **WHEN** `node site/docs/scripts/prebuild.mjs` runs on Windows or in an environment without `rsync`, `shdoc`, or `task`
- **THEN** canonical `docs/` files are mirrored (excluding repo governance files), autogenerated script and CLI command directories are populated with MDX-valid markdown, and exit status is `0`
