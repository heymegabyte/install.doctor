# Consume pinned MCP host manifests

**Architect Role:** assigned

## Why

Install Doctor currently maintains an independent portal descriptor instead of consuming the canonical host manifests generated by `heymegabyte/mcp.megabyte.space`. That permits endpoint, runtime-secret-reference, and merge-policy drift.

## Outcome

Pin an exact canonical control-plane revision and artifact digests, verify the selected macOS or Ubuntu human and automation manifests before use, and install them transactionally while preserving unrelated client entries. Collisions fail closed and every applied change has a mode-0600 rollback snapshot and metadata-only receipt.

## Scope

- Secret-free host manifest acquisition and SHA-256 verification.
- macOS and Ubuntu host-class selection.
- Atomic host descriptor and optional JSON MCP client merge.
- Collision detection, unrelated-entry preservation, and rollback.
- Focused tests and operator documentation.

No credential resolution, portal mutation, client canary promotion, or removal of local-only MCP servers is included.
